Use Claude models in chat by signing in with your Anthropic Console account. Usage is billed at API rates to the Console organization you choose, so it needs Console credits. It does not use a Claude Pro or Max plan.

Appearance

Light or dark, and the color of the window.

Browser appearance

Theme color

Right-click the sidebar and choose Panel Color. The color applies to the sidebar, the top bar, chat, the new-tab page and these settings.

New-tab background

Open a new tab and click the gear in the top-right corner to pick a color, gradient or image for light and dark mode.

Favorites

The app icons at the top of the sidebar, up to 12. Reorder, rename, or remove them here, or right-click an icon. The + tile adds the page you are on.

Favorites

Bookmarks

Tabs that stay open in the Bookmarks group. Add, rename, reorder, or remove them. Changes show up in the sidebar right away.

Bookmarks

Updates

Xplor checks for updates automatically and installs them in the background. Turn that off or check on demand here.

Automatic updates

When on, Xplor checks once a day and lets you know when a new version is available.

Check now

Runs an immediate check; Xplor shows a dialog if an update is available.
